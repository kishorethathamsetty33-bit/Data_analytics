“This project is a Retail Store Sales Analysis Dashboard developed using Power BI. 
In this project, I worked with retail transaction data and analyzed 
sales, quantity, customers, categories, locations, payment methods, and discounts.
I cleaned and prepared the data, created important KPIs and different visualizations, 
and added slicers to make the dashboard interactive. 
The main purpose of this project is to understand retail sales performance and present 
the data in a simple and easy-to-understand dashboard.
Through this project, I gained practical experience in data cleaning, analysis, visualization, and Power BI.”
